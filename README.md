# 饭票

按预算、按热量，把每天的健身餐排好的 App。面向所有健身的人：增肌、减脂、保持都能用。

版本 1.7.1 · 安卓包名 `com.fanpiao.app`

---

## 一、这个压缩包里有什么

## 二、App 能做什么

1. **建档**：填性别、年龄、身高、体重，选增肌、减脂或保持。App 算出每天该吃多少热量、蛋白、脂肪、碳水。
2. **今天吃什么**：自动排好早餐、午餐、晚餐、加餐。每样食物写清楚吃多少、多少千卡、多少蛋白、多少钱。
3. **每餐三种吃法**：食堂/外面吃、不开火、自己做。每一餐都能单独选，选完自动重排。
4. **按预算排**：设了每天预算，排出来的不会超。
5. **手表热量**：填上手表今天的活动千卡，目标会跟着变。
6. **打勾记录**：吃完一样点一下。已经吃的不会被重排改掉。
7. **改起来方便**：点任何一样食物，可以加减数量、换成同类的别的食物、删掉。
8. **AI 排餐**：填上自己的模型密钥后，AI 按你的要求（比如"今天练腿"）选搭配，App 再把数量算准。
9. **食物库**：内置 70 多种常见食物，能改价格和营养，能加自己的食物，AI 还能帮忙估营养。
10. **拍一下加食物（1.3.0 新）**：拍一盘饭菜、一个包装或营养成分表，AI 认出是什么、估出热量蛋白和价格，勾一下就加进食物库，还能顺手记到今天哪一餐（直接打勾）。
11. **钠和膳食纤维（1.4.0 新）**：每样食物都有钠和膳食纤维的数值。「今天」页有一张卡片，显示今天的钠（换算成几克盐）和膳食纤维，和建议量比一比；点开能看到主要来自哪几样、怎么少吃点盐，纤维不够时点一下就能把高纤维的食物加进合适的那一餐。排餐时也会尽量让钠不超标、纤维吃够（但不会为此牺牲热量和蛋白）。「记录」页能看每天的钠和纤维。
10. **采购清单**：一键算出 3 天、7 天或 14 天要买什么、大约多少钱。
11. **记录**：最近 7 天或 30 天的热量、蛋白、花费图表，体重曲线，本月吃饭总花费。
12. **数据都在手机上**：不注册、不联网也能用。可以导出、导入。
13. **让 AI 帮你填（1.7.0 新）**：「我的 → 让 AI 帮你填」（新用户在建档第一页也有）。复制一段说明给任何 AI（DeepSeek、豆包、ChatGPT、Claude 都行），它问你几个问题，再把身高体重、目标、三餐在哪吃、预算、常吃的食物和补剂、体重记录、甚至排好的几天饭写成一段数据；粘贴回来先看「会改什么」，确认后才导入。填了模型密钥的，也可以直接在 App 里用大白话让 AI 写。别的程序可以用 `fanpiao://import?data=…` 链接打开导入页。格式公开，见 `docs/AI接口.md`。

### 和别的饮食 App 比，不一样在哪里

- 别的 App 多数是"你吃完了来记账"。饭票是**先帮你排好，照着吃**。
- 排餐时同时考虑**钱**和**做饭条件**（食堂、不开火、能开火），这是学生和上班族最实际的两个限制。
- AI 只负责"选什么"，**数量由本地算法算**，所以热量和蛋白的数字是准的，不会出现 AI 算错数的情况。
- 不强制注册，没有广告，数据不上传。

## 设计和动效（1.1.0 重做，1.2.0 加了全屏动画）

**整体思路**：界面本身只用黑、白、灰，颜色全部留给两样东西：最上面的「天空」和打勾的绿色。这样眼睛会先看到进度，再看到要吃什么。

**天空和弧线**：「今天」页最上面是一片天空，颜色跟着真实时间变（清晨、白天、傍晚、夜里各一套，夜里有星星）。一条从左到右的弧线代表今天：太阳在弧线上的位置就是你已经吃了多少，弧线上的四个点是早、午、晚、加餐，吃完一餐那个点会亮。

**用到的心理学原则**

| 原则 | 在 App 里怎么做的 |
|---|---|
| 目标渐近效应：离目标越近越有动力 | 弧线和"还可以吃多少千卡"，让人一眼看到离终点多远 |
| 禀赋进度效应：起点不是零更容易坚持 | 太阳一开始就在地平线上方一点，不从空白开始 |
| 即时正反馈 | 打勾时圆圈弹一下、迸出小粒子、手机轻震、数字滚动、太阳往前走 |
| 蔡格尼克效应：没做完的事会记得 | 弧线上没亮的点、没打勾的圆圈 |
| 峰终定律：结尾的感受决定整体印象 | 一天全部吃完时放彩带，并说一句肯定的话 |
| 希克定律：选择越少决定越快 | 每个页面只有一个黑色主按钮 |
| 不评判的设计（对饮食类 App 很重要） | 吃多了、吃少了都不用红色，不用"超标""失败"这类词，只给中性的建议 |
| 自主感 | 每样食物都能改数量、换别的、删掉；连续记录只显示天数，不催人 |

**动效清单**

- 进页面：卡片依次浮上来，弧线画出来，数字从 0 滚到实际值
- 天空：两团光慢慢飘，太阳一呼一吸，夜里星星闪
- 打勾：圆圈回弹、对勾画出来、文字被划掉、粒子迸开、轻震
- 一餐吃完：图标变绿转一下，出现"吃完了"标记，弧线上的点扩散一圈
- 全天吃完：彩带
- 换一份 / AI 排餐：每餐卡片依次重新浮现；AI 思考时有一圈流动的彩色边框
- 弹出面板：从底部弹起，后面的页面缩小变暗；可以按住顶部往下拖着关掉
- 底部标签栏：悬浮的毛玻璃，选中的底色滑过去，图标弹一下
- 分段选择、开关：底色和圆钮带回弹地滑动
- 往下滚：顶部出现毛玻璃标题栏
- 图表：柱子长出来，折线画出来
- 手机开了"减少动态效果"时，以上动效自动关闭

**1.2.0 新加的全屏动画**（上面的全部保留）

| 什么时候出现 | 画面 |
|---|---|
| 打开 App | 整屏天空 + 按时间说的问候语（早上好 / 中午好…），字一个一个浮上来，太阳沿弧线升起，然后整屏缩小、变成首页那张天空卡片 |
| 建完档点「开始用」 | 整屏显示"正在为你计算"，热量和蛋白的数字滚出来，再收进首页 |
| 点「AI 排餐」 | 整屏夜空，一圈光环转动，你的食物名字一个个飘过，表示 AI 正在挑；可以点「停止」 |
| 点「换一份」 | 一圈颜色从你手指按的地方扩散到整屏，再收回去，底下的菜已经换好 |
| 一天全部吃完 | 整屏傍晚天空 + 烟花 + 彩带，显示今天的热量、蛋白、花费 |

**1.2.0 新加的小动效**

- 数字像里程表一样一位一位滚动
- 天空卡片：手指按住会跟着倾斜，有一块光斑跟着手指走；多了云、光芒和偶尔划过的流星
- 往下滚时天空卡片有视差（里面的东西比卡片动得慢）
- 切换底部标签：页面按方向左右滑进来
- 所有按钮按下去有一圈水波
- 每餐卡片滚到眼前才浮现；一餐吃完时有一道光扫过去
- 建档三步：天空从清晨渐变到白天再到傍晚，食物小标签像波浪一样依次出现

**1.4.0 钠和膳食纤维的动效**

- 盐瓶图标：每次钠变了就倾斜抖一抖，撒下几粒盐
- 钠超过建议上限：进度条变成琥珀色、斜纹慢慢流动，上限那根线一下一下发光（不用红色，不吓人）
- 叶子图标：一直轻轻摆；纤维一够，旁边长出第二片小叶子，冒出绿色粒子，手机轻震
- 进度条：浅色是今天的安排、深色是已经吃了的，滚到眼前才长出来
- 详情面板：半圆仪表从 0 画到当前值；盐换算成「啤酒瓶盖」，瓶盖一个个转进来、里面的盐慢慢填满；「主要来自」的条一根根长出来
- 点「想多一点纤维」里的食物：按钮迸出绿色粒子，仪表的数字往上滚

**建议量从哪来**：钠按《中国居民膳食指南》每天不超过 2000 mg（约 5 g 盐）；膳食纤维每天 25 g 以上，吃得多的人按每 1000 千卡 12 g 算，最多 35 g。食物的钠和纤维取常见值，包装食品请以营养成分表为准，在「食物」页点进去能改。

**1.5.0 改成苹果「健康 / 健身记录」的质感**

- 「今天」最上面换成三个圆环（像 Apple Watch 的健身圆环）：外圈热量（红）、中圈蛋白质（绿）、内圈碳水（蓝），旁边是数字，下面一条黄色是脂肪。浅色的一段是今天的安排，亮色是已经吃的；吃超了圆环会接着绕第二圈，圆环末端有一点阴影。
- 卡片背景：深色模式纯黑底 + 深灰卡片，浅色模式浅灰底 + 白卡片，都不加阴影；卡片右上角有一团很淡的光，颜色跟着清晨、白天、傍晚、夜里变。
- 颜色只用苹果的系统色：按钮是苹果蓝的胶囊，普通按钮是灰底蓝字；早餐橙、午餐青、晚餐靛蓝、加餐粉，标题跟着变色，像「健康」App 的分类。标签、提示条的淡色底用 Radix Colors 的配色，深浅模式对比度都够。
- 「我的」页每一项前面有彩色小图标，像 iPhone 的「设置」。
- 底部标签栏是「液态玻璃」：一圈接住光的亮边；选中的胶囊换位置时像液体一样先拉长再回弹；在安卓上，玻璃边缘还会把背后的内容弯折（折射）。iPhone 的浏览器内核不支持这种折射，会自动变成普通毛玻璃。思路参考开源项目 liquid-glass-react（MIT 许可）。
- 1.5.1 把玻璃改得更透：底色更淡、模糊更少，能看清后面的内容；用上沿亮线、下沿暗影、内圈柔光、外面两层投影做出厚度；选中的那块是一片更亮的小玻璃；顶部标题栏不再有硬边，内容滚上去时慢慢淡进模糊里。
- 1.6.0 底部标签栏学 Apple Music 做成「透明泡泡」：平时选中那格是一块带淡蓝色的胶囊；手指按住时，胶囊鼓成一个比标签栏还大的透明泡泡，边缘有一圈彩虹色的光；按住不放可以左右滑，泡泡跟着手指走，滑得快会被拉长，滑过哪格哪格就变蓝，安卓上每过一格轻震一下；松手泡泡缩回胶囊，停在最近那格并切过去。轻点一下照样能切换。安卓上泡泡还会轻微弯折后面的内容（像放大镜的边），iPhone 上是透明泡泡加彩虹边。
- 1.6.1 首页换成学 Apple Music 首页大封面的「彩色封面卡」：背景是慢慢流动的四团颜色，跟着时间自动换四套（早上 5–9 点暖橙粉、白天 9–16 点天蓝、傍晚 16–19 点橙红紫、夜里深蓝紫）；中间一个大数字「今天还可以吃多少千卡」；下面一条玻璃进度槽，白色是已经吃的、浅色是今天安排的，头上一颗透明泡泡，打勾吃东西时进度弹着往前走、泡泡挤扁一下、一道光扫过去；蛋白质、碳水、脂肪三块半透明玻璃小卡。所有卡片加了专辑封面那种细细的玻璃亮边（左上和右下最亮）。
- 1.6.1 新增「拍包装加食物」：有包装的食品只认包装背面的营养成分表（不同牌子差很多，所以不估）。第 1 张拍营养成分表，第 2 张可以再拍正面（认名字和净含量，可跳过）。AI 只照着表抄数字，千焦换千卡、按整包换算、核对数字对不对得上都由 App 自己算；读出来的结果排成和包装一样的表，每格都能改，热量和三大营养素对不上会提醒你对照照片检查。净含量 1000g 以内按「一整包」记，更大的按 100g 记，也可以自己切换。入口：「食物」页的「拍包装加食物」、「手动加食物」里的提示、拍饭菜时认出是包装食品也会提醒你改拍营养成分表。
- 手感按 Emil Kowalski 的 apple-design / mobile-native 规则调过：按下立刻有反馈、点按没有灰色闪块、没有 300ms 延迟、数字等宽不抖、动画曲线换成更干脆的 ease-out、回弹更收敛；面板可以「往下一甩」就关，往上拉有橡皮筋阻力；系统开了「降低透明度」「增强对比度」都会跟着变。
- 以前的全屏动画（开场问候、换一份、AI 排餐、全天吃完的烟花）都还在；天空卡片里的云、流星、太阳弧线换成了圆环。

**不想要全屏动画**：「我的」→ 关掉「全屏动画」开关。小动效还在，只是不再占满整屏。

## 三、安卓手机怎么装

1. 把 `饭票-1.7.1.apk` 发到安卓手机上（微信、QQ、数据线都行）。

## 四、苹果手机怎么办

苹果的安装包（ipa）**必须**用苹果电脑打包，还要有苹果开发者账号（每年 688 元）。`ios/` 文件夹里是写好的工程，以后有条件了按下面做：

1. 在苹果电脑上装好 Xcode（App Store 里免费下载）和 Node.js（nodejs.org 下载）。
2. 把整个文件夹拷到苹果电脑上。打开「终端」，进入这个文件夹，依次运行下面两行。**这一步不能跳过**，iOS 工程要用到它下载的东西：
   ```bash
   npm install
   npx cap sync ios
   ```
3. 双击打开 `ios/App/App.xcodeproj`。第一次打开，Xcode 会自动下载依赖，等它完成。
4. 左边点最上面的 `App`，中间选 `Signing & Capabilities`，在 `Team` 里选你的开发者账号。
5. 把 `Bundle Identifier` 改成你自己的，比如 `com.你的名字.fanpiao`。
6. 手机用数据线连电脑，上面选你的手机，点左上角的三角形 ▶ 就能装到手机上试。
7. 要上架：菜单 `Product → Archive`，然后按提示上传到 App Store Connect。

没有开发者账号也能用**免费的 Apple ID** 装到自己的手机上试，但 7 天后会过期，要重新装。

> `ios/` 工程是在 Linux 上生成的，**没有在 Xcode 里编译过**。它是 Capacitor 官方模板加上我们的界面，一般能直接编译；如果 Xcode 报错，把错误信息发给我。

## 五、怎么接 AI（以 DeepSeek 为例）

饭票不自带 AI 账号。每个用户填自己的密钥，钱直接付给模型公司。

1. 打开 platform.deepseek.com，注册并充值（充 10 元能用很久）。
2. 在网站左边点「API Keys」→「创建 API Key」，复制那一串 `sk-` 开头的字。
3. 打开饭票 →「我的」→「AI 设置」。
4. 「用哪家的模型」选 DeepSeek，把密钥粘贴进去。
5. 点「保存并测试」，显示"连上了，可以用"就好了。
6. 回到「今天」，点「AI 排餐」。

内置了这些服务商：DeepSeek、通义千问、智谱 GLM、Kimi、硅基流动、OpenAI，也可以选"自定义"填任何 OpenAI 兼容的接口。

### 拍一下加食物要用「能看图」的模型

拍照识别要把照片发给一个能看图的模型。在「AI 设置」最下面的「拍照识别」里选：

| 服务商 | 默认识图模型 | 说明 |
|---|---|---|
| DeepSeek | 没有 | DeepSeek 现在不能看图，要在「看照片用哪家」另选一家 |
| 智谱 GLM | glm-4v-flash | 免费，推荐先用这个 |
| 通义千问 | qwen-vl-plus | |
| Kimi | moonshot-v1-8k-vision-preview | |
| 硅基流动 | Qwen/Qwen2.5-VL-72B-Instruct | |
| OpenAI | gpt-4o-mini | |

所以可以「排餐用 DeepSeek，看照片用智谱」，两家各填各的密钥。照片会先缩小到 1024 像素再发，一次大约几十 KB 到两百 KB。

怎么用：「食物」页最上面点「拍一下加食物」→ 拍照或从相册选 → 等几秒 → 看认出来的几样，不对的点「改」→ 选要不要记到今天哪一餐 → 「加入」。在「今天」页某一餐里点加号，也有「拍一下」，拍完直接记到那一餐。

> 各家的接口地址和默认模型名是我按它们的公开文档填的，**没有用真实密钥调用过**（打包环境里连不上这些网站）。
> 我用一个模仿它们接口格式的测试服务器完整测过流程。如果哪家连不上，多半是模型名换了，在「模型名」里改成它官网上现在的名字就行。

### 让任何 AI 帮用户填数据（fanpiao.ai/1，1.7.0 新）

想让别人的 AI 也能帮他填好饭票，就用这个接口。它不需要服务器：AI 写出一段 JSON，用户粘贴进 App，或者程序生成一个 `fanpiao://import?data=…` 链接让用户点开。不管哪种，App 都先给用户看「会改什么」，确认后才写入，而且只合并、不清空，AI 密钥和云端账号永远不会被改。

- 格式说明（给人看）：`docs/AI接口.md`
- 格式定义（给程序校验）：`docs/fanpiao-ai-1.schema.json`
- 生成链接：`node tools/fanpiao-link.mjs 数据.json`
- App 里「复制给 AI 的说明」就是一份完整的提示词，可以直接拿去给任何 AI 用

## 六、预留的服务器接口

App 默认**不连任何服务器**。接口先留好了，以后要做账号、云备份、或者由你统一提供 AI，就把服务器开起来。

### 有哪些接口

| 接口 | 作用 |
|---|---|
| `GET /v1/health` | 服务器是否正常 |
| `GET /v1/foods` | 公共食物库 |
| `POST /v1/auth/register` | 注册 |
| `POST /v1/auth/login` | 登录 |
| `POST /v1/auth/logout` | 退出登录 |
| `DELETE /v1/account` | 注销账号并删除数据 |
| `GET /v1/state` | 取回备份 |
| `PUT /v1/state` | 上传备份 |
| `POST /v1/ai/chat` | 服务器代用户调 AI |

完整定义在 `server/openapi.yaml`，可以贴到 editor.swagger.io 里看成网页文档。

### 怎么在自己电脑上跑起来试

需要先装 Node.js（18 或更高版本）。

```bash
node server/server.mjs
```

看到"饭票服务器已启动"就行了。然后在 App 的「我的 → 云端账号和备份」里填 `http://你电脑的IP:8787`。

要让服务器代调 AI，启动前设置三个环境变量：

```bash
AI_BASE_URL=https://api.deepseek.com AI_API_KEY=sk-你的密钥 AI_MODEL=deepseek-chat node server/server.mjs
```

然后在 App 的「AI 设置」里选"我的服务器（预留）"。

拍照识别也走服务器的话，再加一个 `AI_VISION_MODEL=识图模型名`（不填就用 AI_MODEL）。带照片的请求服务器会自动换成这个模型；只收 base64 的图片，每次最多 2 张。

### 跑测试

```bash
node server/test.mjs
```

打印 `ALL PASS` 就是 24 项全部通过。

### 正式上线前必须做的

- 服务器要有 **HTTPS**。安卓和苹果的正式包默认不允许连 `http://` 的地址。用 Caddy 或 Nginx 做反向代理。
- 参考程序把数据存在一个 JSON 文件里，适合几百个用户以内。用户多了要换成正式的数据库（比如 PostgreSQL）。
- 服务器在国内的话，域名要备案。

## 七、签名文件，一定要保管好

`signing/` 里有两个文件：

- `fanpiao-release.jks`：签名文件
- `keystore.properties`：里面有密码

**安卓系统靠这个签名认"是不是同一个 App"。** 以后每次出新版本，都必须用同一个签名文件打包，用户才能直接升级。

- 把这两个文件备份到至少两个地方（比如网盘和 U 盘）。
- **不要发给别人，不要传到公开的代码仓库。**
- 丢了就再也没法给老用户升级，只能让他们卸载重装，数据会丢。

## 八、怎么改 App、重新打包

改界面或逻辑：改 `www/` 里的文件。主要文件：

| 文件 | 管什么 |
|---|---|
| `www/js/foods.js` | 内置食物库（加食物、改默认价格改这里） |
| `www/js/nutrition.js` | 热量和蛋白目标的计算公式 |
| `www/js/planner.js` | 本地排餐算法 |
| `www/js/ai.js` | AI 服务商列表和提示词（包括拍照识别的提示词） |
| `www/js/snap.js` | 拍一下加食物：选照片、压缩、扫描动画、识别结果 |
| `www/js/today.js` | 「今天」页（天空、弧线、每餐卡片） |
| `www/js/fx.js` | 动效：数字滚动、打勾的粒子、彩带、震动 |
| `www/js/foodsview.js` | 「食物」页 |
| `www/js/records.js` | 「记录」页 |
| `www/js/me.js` | 「我的」页和各种设置 |
| `www/styles.css` | 颜色、字体、版式 |

改完重新打包安卓（需要装 Node.js、JDK 21、Android SDK）：

```bash
npm install
npm run sync
cd android && ./gradlew assembleRelease
```

`npm run sync` 会先把 `www/` 打包成 `dist/`（所有代码合成一个文件、变量名换成乱码、界面文字编码藏起来），再拷进安卓和苹果工程。**自己改代码永远改 `www/`**，`dist/` 每次都会重新生成，别改它。打乱后别人解开安装包很难看懂、也很难照抄；但装在别人手机上的程序没法做到绝对破解不了。

新的 apk 在 `android/app/build/outputs/apk/release/`。

- 改 App 名字：`capacitor.config.json` 里的 `appName`，改完 `npm run sync`。
- 改包名：`capacitor.config.json` 里的 `appId`，还有 `android/app/build.gradle` 里的 `applicationId` 和 `namespace`。**上架后就不能再改了。**
- 改图标：换掉 `assets/` 里的图，运行 `npx capacitor-assets generate`。
- 出新版本：`android/app/build.gradle` 里 `versionCode` 加 1，`versionName` 改成新版本号。

## 九、想正式上架，还要准备什么

下面是一般情况，**具体以各应用商店当时的要求为准**。

**国内安卓应用商店（华为、小米、OPPO、vivo、应用宝等）**
- 开发者账号。个人能注册的商店有限，很多要求企业资质。
- 软件著作权证书（软著）。自己申请免费，要等一段时间；找代办几百元。
- App 备案。
- 隐私政策网页的链接。App 里已经写了隐私说明，上架时要再做成一个网页。

**苹果 App Store**
- 苹果开发者账号，每年 688 元。
- 一台苹果电脑。
- 隐私政策链接、App 截图、介绍文字。
- 健康饮食类 App，苹果审核会看有没有免责声明。App 里已经有了。

**建议的顺序**：先把 apk 发给身边健身的同学用，收集意见，改几版。确定有人愿意用，再花钱办上架的事。

## 十、现在的限制，要如实知道

1. apk 没在真手机上跑过；iOS 工程没在 Xcode 里编译过。
2. AI 服务商的接口没用真实密钥调过。
3. 食物的营养是典型值，不同品牌有差别。用户应该按包装改。
4. 本地排餐是"找一个够好的搭配"，不保证是最好的。预算太低或勾选的食物太少时，会排不到目标，App 会提示。
5. 数据只在手机上，卸载就没了。要提醒用户先导出。
6. 这是饮食参考工具，不是医疗建议。未满 18 岁不提供减脂目标，热量有安全下限（男 1500、女 1200 千卡）。
