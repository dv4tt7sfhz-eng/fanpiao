# 饭票 2.1.0 动效清单：20 个过场 + 150 个点击小动画

照 Norg 录屏（点「安排训练→」）做的。内容一样没改，改的只是点了以后怎么动。

## 一、过场：大框长出来，小框飞过去

规则（写在 `www/js/fly.js`）：

- **大框**：点哪个框，新的面板或整页就从这个框里长出来。一开始是按钮的颜色和大小，长到一半换成面板的颜色，里面的内容晚一点淡进来。关的时候倒着缩回那个按钮，按钮再「接住」弹一下。
- **小框**：两边都有同一个 `data-fly` 名字的东西，会从旧位置飞到新位置；关的时候飞回去。长条按钮飞的时候宽高一起变，字不变形（`data-fly-m="w"`）；数字和标题按高度等比缩放。
- **按钮上的字**：飞过去变成面板的标题。
- **时间**（从录屏一帧一帧量的，60 帧录屏按 30 帧取样）：
  - 大框 0.46 秒，曲线 `cubic-bezier(.1,.8,.05,1)`：33 毫秒就长了 47%，66 毫秒 74%，后面慢慢贴边。
  - 小框 0.4 秒，曲线 `cubic-bezier(.2,.6,.25,1)`：33 毫秒走 19%，100 毫秒 46%，233 毫秒 87%。
  - 关的时候 0.29–0.3 秒，比打开快。

## 二、150 个点击小动画（写在 `www/styles.css` 最后「2.1.0 点击小动画」）

- 点下去的瞬间（按住时）：`:active`
- 松手以后：脚本给被点的东西打上 `data-tk`，外面一层打上 `data-tkp`，1 秒后拿掉
- 会弹出面板的按钮，松手后马上被面板盖住，所以它们的小动作放在「按住」和「面板缩回来时接住」（`data-back`）
- 系统里开了「减少动态效果」时全部不播
