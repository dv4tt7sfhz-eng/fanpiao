# 饭票 2.2.0 调色：液体玻璃

这一版只改颜色和材质，不改内容、不改动画。全部写在 `www/styles.css` 最后一段（「2.2.0 调色：液体玻璃」），另外只动了 `www/js/art.js` 里碗后面那团光的颜色。

## 想的画面

一片有颜色的暗光（像夜里透过水的霓虹），上面浮着一块块玻璃。

## 四条规矩

1. **光场**：整屏最底下铺三束光，钉在屏幕上不跟着滚。
   - 主光：左上，主题色（`--lf-a`）
   - 冷光：右边，主题色对面的冷色（`--lf-b`）
   - 暖光：左下（`--lf-c`）
   - 合起来是 `--lf`。画在 `body::before` 上；整页（`.dp-box::before`）、拍摄页、智能食谱页用同一片光。
2. **玻璃**分四种：
   - `--gl-1` 卡片：半透明，左上一片反光，右下透着冷光。自己不模糊（光场本来就是柔的）。
   - `--gl-2` 凸起的小件：按钮、标签、圆钮。
   - `--well` 槽：输入框、分段选择的底、进度条的轨道——是凹下去的。
   - `--gl-3` 浮着的：底栏、浮窗、提示。只有这一种真的模糊后面的东西。
   - 亮边：左上一道白、右下一道带冷色的（`--gl-1-rim` 等）。
3. **主题色分三段**：亮面往暖色偏（`--tint-hi`）、本色（`--tint`）、暗面往冷色偏（`--tint-lo`），最深 `--tint-deep`。有颜色的玻璃用 `--gl-tint`。
4. **其余颜色**在同一亮度上重新配了一遍（用 OKLCH 算的）。

## 这一版没做的

- 没跑功能检查（交给负责检查的模型）。调色时把所有画面截过一遍图，脚本没有报错，但这不等于功能测试。
- 浮着的玻璃（底栏、浮窗）靠 `backdrop-filter` 模糊后面的内容。在无头浏览器截图里，首页餐卡上的字有时没被模糊（2.1.0 也是这样），所以这几块玻璃的底色调厚了一点（约 62% 不透明），不靠模糊也看得清。真机上模糊是否正常，需要检查的人确认。
- 封面「计划」那一面，碗的左边被卡片切成一条直边——2.1.0 就是这样，这次没动。
