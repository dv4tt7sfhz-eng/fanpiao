这份文档是**设计稿**，不是做完的功能。App 本身（`www/`）这一轮没有改，只多了一个还没接上的零件文件 `www/js/motion.js`。

## 0. 一句话方向

参考的是抖音上那个 Norg（健身 + 饮食 App）。**不学它的长相**（黑底、红色、肌肉人插画都不要），**只学它「怎么动」**。饭票的长相保持现在的样子：浅灰底、白卡片、首页一张彩色封面、底下一条玻璃标签栏。

## 2. 配色和材质（只做深色）

**用户要求：只设计深色模式，要有质感的光影。** 样式在 `docs/motion-proto/dark.css`，要整段搬进 App，并且让 App 永远用深色（`<html data-theme="dark">`，「我的」里不再给浅色选项）。

### 2.1 思路：暗房里的磨砂玻璃和金属

1. **底**：带一点暖的近黑 `#0b0b0e`。顶上有一盏很淡的主题色环境光（`radial-gradient` 16%），整屏铺一层细噪点（SVG `feTurbulence`，透明度 4.5%，`mix-blend-mode:overlay`），像胶片颗粒，去掉数码感。
2. **卡片**：竖向渐变 `#1b1b21 → #141418 → #111115`（上亮下暗，光从上面来）。上沿 1px 高光 `rgba(255,255,255,.075)`，下沿 1px 暗线 `rgba(0,0,0,.5)`，外面一圈很长很软的黑影 `0 24px 48px -24px rgba(0,0,0,.9)`。左上角再叠一团 3.5% 的白光。
3. **彩色只给「发光体」**：封面、日型、选中的东西。发光体自己带同色外发光（低透明、大模糊），照亮周围。其余全是灰。
4. **封面 = 深色宝石**：底色压到几乎黑，亮色只在左上角一团，右下角一团次色；上面一道斜着的宽镜面高光（115°，7%），四周暗角（45%）。
5. **大数字像金属**：白到 `#a9a9b6` 的竖向渐变字（`background-clip:text`）。
6. **按钮像糖**：主题色上亮下暗三段渐变 + 上沿内高光 + 同色外发光。

## 3. 动效规则（所有动画都守这几条）

1. **曲线只用老的三条**：`--smooth`（面板、整页）、`--out`（进度、数字、出现）、`--spring`（回弹、按下松开）。
2. **时长分四档**：按下 0.12 秒；小东西 0.3–0.5 秒；一块内容 0.55–0.75 秒；整页过场 0.5–0.8 秒。
3. **出现的样子统一**：从下面 14–28px 浮上来 + 从模糊变清楚 + 从透明变实。一组东西错开 45–70 毫秒。
4. **按下的样子统一**：缩到 0.94–0.97；松手用 `--spring` 弹回。
5. **一直在动的东西要很轻**：呼吸的光圈 2.2–2.6 秒一次，封面色块 14–22 秒一次。
6. **减少动态效果**：系统开了以后，`styles.css` 第 520 行那条总规则会把所有动画压到几乎 0 秒。新加的 js 动画都要先判断 `calm()`（在 `fx.js`）。
7. **全屏过场**要判断 `fullFx(S)`，关了就直接切，不播。

## 6. 六个过场动画，单独再说一遍

1. **封面长成整页**（#89–#92，分镜 ④）。先用 `getBoundingClientRect()` 量出首页封面的位置，写进详情页的 `--it --ir --ib --il`，详情页一开始用 `clip-path: inset(...)` 只露出那一块，再放开到 `inset(0)`。返回时反过来。写法见样例里的 `P.expand()`。
2. **面板升起**（#53–#57，分镜 ⑤）。原来就有升起，这次只是加了后面变糊、小横条、标题、× 的出现。
3. **面板换面板**（#94）。在 `app.js` 的 `openSheet` 里判断：如果已经有面板开着，就给 `<html>` 加 0.5 秒的 `sheet-push`。样式：`.sheet-push .shade,.sheet-push .sheet{animation:none}`，`.sheet-push .sh,.sheet-push .sb{animation:pushin .5s var(--smooth)}`，`@keyframes pushin{from{opacity:0;transform:translateX(40px)}}`。
4. **小封面飞到大封面**（#51）。点计划卡片时调 `rememberCover(小封面元素)`；设置面板里给大封面一个 ref，调 `useCoverLanding(ref)`。
5. **换主题色**（#71，分镜 ⑦）。写法见样例里的 `P.accent()`：先把点的中心写进 `--tx --ty`，把到最远屏幕角的距离写进 `--tr`，再 `document.startViewTransition(改颜色)`。
6. **换计划的全屏过场**（#114）。在 `fullscreen.js` 里照着 `Wipe` 新写一个 `PlanSwitch`，在 `app.js` 的 `FSC` 里登记成 `plan`。时间线：0 秒漫开 → 0.43 秒真正保存并关面板（`onMid`）→ 0.5 秒柱子弹起 → 0.7 秒名字出现 → 1.1 秒数字数上来 → 1.6 秒开始收 → 2.2 秒结束。

## 9. 已经踩过的坑

- **不要用 `.spark` 这个类名**，老样式里有（AI 思考的星星），会让折线转起来。样例里叫 `.spk`。
- `@property` 登记过的变量（`--g1…--g4`、`--a`、`--n`）才能渐变。老一点的 WebView 不认，那时颜色会直接跳过去，不会坏。
- 分镜图是把动画「停」在某一毫秒截的。**换主题色中间漫开的那一帧截不出来**（浏览器的限制），所以分镜 ⑦ 只有「之前、刚开始、之后」，中间要在手机上看。
- 样例里的数字（1157、60.4 这些）是写死的假数。
- 换天、快捷栏、小卡、详情页、主题色是**新的界面**，不只是加动画。接的时候功能也要一起做。
