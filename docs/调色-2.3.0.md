# 饭票 2.3.0 调色：雾面玻璃（苹果风低饱和）

用户从 4 套苹果风方案里选了第 1 套「雾面玻璃」。写在 `www/styles.css` 最后两段（「2.3.0 调色：雾面玻璃」和「把旧样式里剩下的彩虹和高饱和色也压下来」），排在 2.2.0 那段后面，后写的覆盖先写的。

## 规矩
- **颜色**：所有颜色在 OKLCH 里算，鲜艳度 C 压到 0.055~0.08（2.2.0 是 0.2 以上）。
- **材质只有一种**：iOS 磨砂玻璃。卡片 `--gl-1` 是 8.5%→4.5% 的白，边是 0.5px 发丝线 + 顶上 1px 高光；浮在上面的（底栏、浮窗）是 `rgba(40,40,44,.62)` 加模糊。
- **底**：纯黑 `#000`，背后三团很淡的柔光（主题色 / 灰蓝 / 暖灰）。
- **字**：`#f5f5f7`、62%、34% 三级。
- **封面计划面**：一块透着主题色的玻璃，不再是实色块。
- **彩虹边、彩色图标**：全部改成跟主题色或低饱和记号走。

## 没做的

- 封面上碗的插画（蛋黄、西兰花）保留原色，是食物本身的颜色。
